# Доска по физике

Доска для занятий на Next.js и tldraw. Опубликованная версия: https://physics-board.vercel.app.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Личная доска сохраняется в браузере. Для совместных комнат задайте `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` и серверный `SUPABASE_SECRET_KEY` в `.env.local` и в окружении хостинга. Подойдёт ключ Supabase `sb_secret_…` или прежний `service_role`. Примените миграции из `supabase/migrations` перед запуском новой версии приложения. После обновления участники должны перезагрузить открытые вкладки.

Для публикации на HTTPS-домене нужен действующий ключ tldraw: задайте `NEXT_PUBLIC_TLDRAW_LICENSE_KEY` для сборки. Ключ должен разрешать домен доски. На localhost ключ не требуется; без него опубликованный редактор скрывается через пять секунд. Условия и варианты ключей описаны в [документации tldraw](https://tldraw.dev/sdk-features/license-key).

## Возможности

Карандаш, маркер, ластик (объект целиком или часть штриха), текст, фигуры и стрелки; настройка цвета и фона; клетчатая сетка и независимая привязка к ней; редактируемые физические заготовки. Изображения и PDF открываются в плавающих окнах, которые можно перемещать, изменять в размере, сворачивать и закреплять поверх других окон. PDF можно листать и переносить на доску целиком или фрагментом.

Кнопка «Поделиться» сохраняет доску в облачной комнате и выдаёт ссылку для входа без регистрации. Участники видят изменения доски, курсоры и открытые материалы; страница PDF синхронизируется. Ссылка даёт право редактировать доску каждому, у кого она есть, поэтому передавайте её только участникам занятия. При сбое Supabase ранее открытая доска загружается из локальной копии. Правки отправляются после восстановления соединения.

Файлы комнаты хранятся в закрытом Supabase Storage, ограничение одного файла — 50 МиБ. Для отображения выдаются временные ссылки. Окна файлов личной доски нужно открыть заново после обновления страницы.

## Проверка

Установите Chromium командой `npx playwright install chromium`, затем выполните `npm test`. Облачные интеграционные тесты запускаются отдельно с `RUN_CLOUD_INTEGRATION=1`; они создают временные анонимные аккаунты и записывают их идентификаторы в `.cloud-test-users.json` для административной очистки.

## Локальная комната для разработки

`npm run sync:dev` запускает отдельный сервер для экспериментов на одном компьютере. Его данные находятся в `.rooms`; он не используется облачной версией.
